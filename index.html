Apple Calendar on Mac

Paste the feed link into the Calendar app.
  1. Open the Calendar app on your Mac (not a browser).
  2. In the menu bar, choose File → New Calendar Subscription…
  3. Paste this link:
  4. Click Subscribe, name it (for example, SEE Events), set Auto-refresh to Every day, and click OK.

On iPhone, events can take up to an hour to appear. To force a refresh, go to Settings → Calendar → Accounts, tap the subscribed calendar, and toggle it off and on.

Microsoft Outlook

Subscribe from the web or the desktop app.

Use this link in every version of Outlook:

Outlook on the web and new Outlook

  1. Open Calendar and click Add calendar.
  2. Choose Subscribe from web and paste the link.
  3. Name it and click Import.

Outlook desktop (365)

  1. Go to File → Account Settings → Account Settings…
  2. Open the Internet Calendars tab and click New…
  3. Paste the link, click Add, name it, and click OK.

The first sync can take up to 24 hours. To force it, right-click the calendar in the sidebar and choose Sync, or press F9 in Outlook desktop. Not sure which version you have? If you see a “Try the new Outlook” toggle, use the desktop steps.
